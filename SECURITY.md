# Política de Segurança — PortfolioHUB

## Objetivo

Documentar as práticas básicas de segurança adotadas no projeto acadêmico PortfolioHUB.

## Boas práticas

- Não armazenar senhas, tokens ou chaves privadas no código público.
- Consultar repositórios públicos do GitHub sem expor credenciais.
- Revisar as permissões de acesso ao repositório.
- Manter o código e a documentação atualizados.
- Verificar alertas de segurança disponibilizados pelo GitHub.

## Comunicação de vulnerabilidades

Problemas de segurança identificados devem ser analisados e corrigidos antes de uma nova publicação. A comunicação deve ocorrer por um canal privado, evitando a exposição pública de informações sensíveis.

## Escopo e limitações

Esta política se aplica ao código e à documentação deste repositório. Ela não representa uma auditoria completa e não garante a ausência de vulnerabilidades.
