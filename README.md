# Meu Study Hub TI

Portfólio acadêmico e profissional desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

## Sobre o projeto

O Meu Study Hub TI tem como objetivo organizar minha trajetória acadêmica, documentar atividades práticas e apresentar projetos desenvolvidos durante minha formação na área de Tecnologia da Informação.

Este repositório também faz parte do desafio de entrega intermediária do Bootcamp I, que aborda organização de projetos, versionamento com Git e GitHub, documentação e publicação de páginas web.

## Objetivos

- Organizar atividades e projetos acadêmicos.
- Documentar conhecimentos adquiridos durante o curso.
- Praticar versionamento de código com Git e GitHub.
- Construir um portfólio para apresentação profissional.
- Compartilhar projetos e facilitar o acesso às atividades desenvolvidas.

## Estrutura do repositório

- `01_Apresentacao_e_Perfil/` — informações acadêmicas e profissionais.
- `02_Disciplinas_Atuais/` — atividades, anotações e resumos das disciplinas.
- `03_Projetos_e_Certificados/` — projetos pessoais, acadêmicos e certificados.
- `index.html` — página inicial do portfólio.
- `README.md` — documentação principal do repositório.
