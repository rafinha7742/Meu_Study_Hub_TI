# PortfolioHUB — Portfólio de Tecnologia da Informação

## Sobre o projeto

O PortfolioHUB é um portfólio acadêmico desenvolvido para organizar e apresentar projetos, conhecimentos e atividades realizados durante minha formação em Análise e Desenvolvimento de Sistemas.

O projeto utiliza o GitHub para armazenar o código-fonte e disponibilizar informações sobre os repositórios públicos.

## Objetivos

- Apresentar projetos acadêmicos e pessoais.
- Demonstrar conhecimentos em desenvolvimento web.
- Integrar o portfólio à API pública do GitHub.
- Aplicar práticas de versionamento e organização de código.
- Documentar cuidados básicos de segurança e testes.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages
- API REST pública do GitHub

## Funcionalidades

- Navegação entre as seções do portfólio.
- Apresentação de informações acadêmicas e tecnológicas.
- Carregamento automático de repositórios públicos próprios do GitHub.
- Exibição do nome, descrição e linguagem principal dos projetos.
- Links para acessar os repositórios.
- Layout adaptável a diferentes tamanhos de tela.
- Mensagens de carregamento e tratamento de falhas na consulta à API.

## Como executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Para testar a integração, mantenha uma conexão com a internet, pois os projetos são consultados na API pública do GitHub.

## Segurança

- A listagem de repositórios públicos utiliza a API pública do GitHub sem necessidade de token.
- Não devem ser inseridas senhas, tokens ou chaves privadas no código executado no navegador.
- Os links externos devem ser utilizados com cuidado.
- As permissões do repositório devem ser revisadas antes de compartilhar o projeto.

## Testes

A listagem de repositórios foi testada no site publicado e os projetos apareceram corretamente.

Outros testes, como navegação por teclado, responsividade em diferentes dispositivos e análise do console do navegador, devem ser registrados após sua execução.
